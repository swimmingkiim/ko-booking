# 1단계: 개인사업자 세무 서비스 분석

조사일: 2026-10-26. 범위: 머니핀·쌤157의 공식 공개 문서.
출처 ID는 [출처 목록](sources.md)을 참조한다.

## 결론

머니핀은 일상적인 거래 정리와 장부 연결, 쌤157은 신고와 오류 발생 후 처리 경험의 참고 대상으로 삼는다. 첫 제품은 파일 가져오기부터 시작해 거래 검토와 계산 근거를 추적할 수 있도록 설계한다. 이는 본 프로젝트의 제안이며 두 서비스의 내부 구현을 확인한 결과가 아니다.

## 공개 자료에서 확인한 기능

| 항목 | 머니핀 | 쌤157 |
| --- | --- | --- |

| 분류·수정 | 태그, 거래 분할, 반복거래 분류, 자동 분류 수동 변경 (MP-01) | 현재 앱의 수정 방식 미확인 |

문서상 머니핀의 부가세 공제 선택 기능은 사용자 수정 가능성의 참고 사례다. 국세청 원문 검증 없이 서비스 설명의 세율·공제 조건을 계산 규칙에 복사하지 않는다.

## 오류 처리에서 도출한 요구사항

쌤157은 2025년 종합소득세 신고 과정에서 자료 수집·계산 오류가 있었고, 일부 신고가 기한 후 처리되었다고 설명한다. 이는 운영사 공개 기록이며 독립 검증은 수행하지 않았다 (SS-03).

이 사례로부터 다음을 제안한다.

- 수집 성공·미수집·자료 없음·인증 실패를 서로 구분한다.
- 예상세액 계산 완료, 제출 요청, 접수 확인을 서로 다른 상태로 표시한다.
- 결과에 사용한 자료와 규칙 버전을 보존해 다시 계산할 수 있게 한다.
- 신고를 지원하는 단계에서는 재시도 전 기존 접수를 조회하고, 중복 제출을 막는다.
- 신고 실패 원인·복구 조치·담당 확인 필요 여부를 사용자에게 보여준다.

## 동일 조건으로 비교할 시나리오

아래는 합성 데이터로 만든 향후 검증 계획이다. 실제 두 서비스에서 실행하지 않았다. 금액은 UX·집계 검증용이며 법적 공제 여부나 세액의 기대값이 아니다.

기본 가정: 국내 개인사업자, 직원 없음, 단일 사업장. 일반·간이·면세 여부는 별도 입력하며 지원 가능한 유형은 공식 규칙 검증 후 정한다.

| ID | 입력·행동 | 본 프로젝트의 검증 기준 |
| --- | --- | --- |
| SC-01 | 같은 거래 파일을 두 번 가져오기 | 중복 후보를 식별하고 재등록 여부를 확인 |
| SC-02 | 카드 결제 110,000원과 대응 계좌 출금 | 증빙과 자금 이동을 연결해 비용 이중 집계 방지 |
| SC-03 | 원거래 110,000원과 부분 취소 22,000원 | 원거래 연결과 순액 88,000원 추적 |
| SC-04 | 사업·개인 지출이 섞인 거래 분류 | 개인 지출 제외 근거와 변경 이력 보존 |

| SC-06 | 자동 제안 분류를 사용자가 수정 | 수정 전후 값·범위·재집계 결과 확인 |
| SC-07 | 원본 파일 일부 누락 또는 잘못된 날짜 | 오류 행·미수집 범위를 표시하고 완전한 자료로 오인하지 않기 |
| SC-08 | 같은 거래를 서로 다른 귀속연도 규칙으로 조회 | 적용 가능한 규칙을 선택하고 근거·버전 표시 |
| SC-09 | 신고 전송 후 응답이 끊김 | 향후 제출 지원 시 접수 여부 확인 전 무조건 재전송 금지 |

예상세액은 3단계에서 공식 예제로 검증한 범위에만 제공한다. 라이브 세무 신고, 인증정보 저장, 유료 연동 계약은 현재 단계의 결과물이 아니다.

## 제안 사용자 흐름

사업자·기간 설정 → 파일 가져오기 → 오류·중복 후보 확인 → 거래 분류·수정 → 장부 확인 → 자료 완전성 확인 → 검증된 범위의 예상세액·근거 → 준비자료 내보내기.

화면은 가져오기, 거래 검토, 장부, 세금·근거의 네 영역으로 시작할 수 있다. 구현 기술과 데이터베이스 선택은 아직 확정하지 않았다.

## 미확인 사항과 완료 범위

- 실제 계정 로그인, 인증, 질문 분기, 접수증 화면은 검증하지 않았다.
- 쌤157 현재 지원 업종·과세유형·요금·계산 상세는 공개 자료만으로 확정할 수 없다.
- 머니핀 일부 페이지는 404·429로 직접 열리지 않아 검색 색인 수준의 근거로 표시했다.
- 독립 명세를 작성했으며 서비스 소스·이미지·문구를 제품 자산으로 복제하지 않았다.
- 1단계의 공개 문서 조사와 초기 요구사항 정의는 완료했다. 실계정 시나리오 검증은 미완료로 남긴다.
- 다음 작업은 2단계 공식 자료 수집기다. 이번 커밋에는 수집기와 앱 코드를 포함하지 않는다.
