# 2단계 검증 기록

검증일: 2026-10-26 (Asia/Seoul).

## 구현 결과

- 국세청 공지에서 연도에 맞는 XLSX 발견·수집·검증.
- 법제처 시행일 기준 법령 목록의 페이지 수집과 특정 판본 본문 수집.
- 원문과 JSON 정형 자료, 출처·시행일·공포일·귀속연도·수집시각의 구분.
- SQLite 트랜잭션과 SHA-256 기반 버전·반복 관측 기록.
- 원문과 정형 자료를 구분하는 변경 감지, 버전별 내보내기.

## 실제 공식 자료로 확인

### 국세청

- [2025년 귀속 경비율 공지](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?bbsId=1143&mi=2207&nttSn=1350751): 게시일 2026-04-29.
- XLSX 1개 시트, 10개 열, 1,542개 업종 파싱 성공.
- 앞자리 0을 포함한 업종코드와 0·누락 값 보존 확인.
- 두 번째 네트워크 수집 결과 `unchanged` 확인.
- 원문 SHA-256: `ebd3fc0fcb92636c3e9cfc5e46af144d665e1e1e860e38e29d4e5b37c0752a4d`.
- 이는 데이터 수집 검증이며 경비율 적용 대상·산식의 세법 검증이 아니다.

### 법제처

- 공식 API 가이드에 공개된 예제 `OC=test`를 명시적으로 사용한 소규모 실연동 검증. 기본 인증값으로 채택하지 않았다.
- `소득세법`, `nw=3` 검색으로 법률·시행령·시행규칙 3개 판본 확인.
- 소득세법 `MST=280405`, `법령ID=001565`, 시행일 `2026-07-01`, 공포일 `2025-12-23` 본문 수집 성공.
- 해당 응답의 조문단위 392개와 부칙·별표 구조를 보존. 조문단위 수는 유효 조문 수를 의미하지 않는다.
- 원문 SHA-256: `38a54fcb82387a39123e6a2dd5cc40c773fe28dca06e6b0def9bcab6e4f74ee8`.
- 운영용 `LAW_OC`는 미설정이며 등록된 사용자 인증값의 운영 권한·한도는 검증하지 않았다.

이 환경의 번들 Python에서는 신뢰 인증서 체인 오류가 발생했고, TLS 검증을 유지하는 `--transport curl`로 실수집했다. 인증서 검증을 비활성화하지 않았다.

## 자동 검증 범위

합성 fixture 기반 단위 테스트 15개 통과. 날짜·연도·중복코드·변경된 열·잘못된 경비율·HTML 오류 응답, 법령ID·시행일 불일치, API 오류코드, 페이지 불일치·부분 수집, 원문 ZIP 보존, 새 버전·동일 버전·원복, 내보내기, 메타데이터 인증값 제거, 외부 호스트 리다이렉트 차단을 확인했다.

실제 수집한 경비율·법령 본문을 내보낸 뒤 DB 메타데이터와 원문 파일의 SHA-256 일치도 확인했다. 문서 내부 링크와 Git 공백 검사도 통과했다.

## 남은 범위

새 귀속연도 게시물 자동 탐색, 주기 실행, 전체 세법 전수 수집, 별표 첨부파일 수집, 조문별 변경 설명, 세액 계산은 이번 구현에 포함하지 않는다. 경비율 자료의 재배포 조건은 확인되지 않았다. 공식 자료와 로컬 DB는 커밋하지 않는다.

다음 단계는 국세청 계산 사례를 기반으로 규칙·기대값과 적용 조건을 검증하는 3단계다. 사용자에게 보고한 뒤 착수한다.
