# 3단계: 계산 규칙 검증 기록

검증일: 2026-10-26 (Asia/Seoul). 규칙 버전: `kr-income-2025.1`.

## 결과

2025년 귀속 종합소득세 기본세율과 단순·기준경비율의 산식 요소를 구현했다. 귀속연도·계산 근거·검토한 자료의 해시를 출력에 연결했다. 최종 납부세액 계산과 적용 자격 자동 판정은 구현하지 않았다.

## 공식 사례와 독립 기대값

| 분류 | 입력 | 기대 결과 | 근거 |
| --- | --- | --- | --- |
| 공식 예제 | 과세표준 30,000,000원 | 기본 산출세액 3,240,000원 | 국세청 세율 안내의 2025년 예시 |
| 공식 예제 | 940908, 수입 45,000,000원, 기본율 75%, 초과율 65% | 사업소득금액 11,750,000원 | 2025년 귀속 경비율 PDF 11쪽 |
| 합성 입력·공식 산식 | 525104, 수입 70,000,000원, 주요경비 20,000,000원, 간편장부대상 | 직접 계산 42,720,000원·비교값 27,440,000원 중 27,440,000원 | PDF 9쪽 산식, 해당연도 XLSX 일반율 10.4%·단순 86% |
| 합성 입력·공식 산식 | 525104, 수입 70,000,000원, 주요경비 50,000,000원, 복식부기의무 | 기준경비율 1/2 적용. 직접 계산 16,360,000원·비교값 33,320,000원 중 16,360,000원 | PDF 9쪽 산식·복식부기 배율 3.4 |

기대값은 구현 함수로 생성하지 않고 출처의 사례 또는 별도의 산술 검토로 기록했다. 기준경비율 사례에서는 최종 선택값뿐 아니라 직접 계산값과 비교값도 각각 검사한다. 잘못된 경비율이 최종 `min` 계산에 가려지는 문제를 방지하기 위해서다.

## 확인한 자료와 원문 보존

- [국세청 세율 안내](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7667&mi=2227): 2023~2025년 표를 확인했으며 이번 규칙의 지원연도는 2025년으로 제한했다. 원문 HTML SHA-256은 `347e731b289cc738d4d22153441d29469e90c1c8fc310506e10a9367e27fab29`.
- [2025년 귀속 경비율 공지](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?bbsId=1143&mi=2207&nttSn=1350751)의 PDF: 9~13쪽 추출과 11쪽 렌더링 확인. PDF SHA-256은 `99fcd9fe626e99562d600eb0bed3727d727995404c16f3e630bc35f4dca7b94e`.
- 2단계의 실제 XLSX 수집 판본과 정형 데이터 SHA-256을 규칙 파일에 고정했다. 525104는 해당 XLSX 1014행, 940908은 1519행에서 확인했다.
- 세율 HTML과 경비율 PDF를 기존 로컬 아카이브에 각각 `nts:tax-brackets:2025:evidence`, `nts:expense-rates:2025:guide`로 보존했다. 이 작업 환경의 버전 ID는 각각 4와 5이며 DB마다 ID는 달라질 수 있다.
- 공식 원문·전체 변환 데이터는 커밋하지 않았다. 저장소에는 산식·수치·출처·해시와 최소 검증 사례만 남겼다.

## 이전 사례를 그대로 사용하지 않은 이유

국세청 [SNS마켓 세무 안내](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7804&mi=2483)의 계산 예제는 2023년 귀속이다. 해당 예제의 525104 기준경비율은 6.6%지만 이번에 수집한 2025년 XLSX는 10.4%다. 과거 예제의 경비율을 현재 자료의 기대값으로 복사하지 않았다.

또한 해당 HTML의 일부 세액 표시는 만원 단위로 간략화되어 있다. 이 표현을 정확한 원 단위 산술의 기대값으로 채택하지 않았다. 이번 테스트의 공식 기대값은 2025년임이 명시되고 산술 결과가 정확하게 제시된 두 사례를 사용했다.

## 검증 범위

자동 테스트는 공식·합성 사례, 8단계 기본세율의 경계, 인적용역 4천만원 경계, 복식부기 기준경비율 1/2, 주요경비 합산, 일반 업종의 비구간 계산, 전역 Decimal 설정 영향 차단, 미지원 연도·조건·입력 거부, 검토하지 않은 자료와 DB 변조 거부, CLI 실행을 포함한다.

- 기존 수집기 15개와 계산 관련 18개, 총 33개 테스트 통과.
- 세율 구간별 누적 산술과 경계 직전·경계·직후 및 난수 100개 대조 통과.
- 실제 국세청 HTML에서 추출한 8개 구간의 상한·세율·누진공제가 규칙 파일과 일치.
- 실제 수집 DB의 경비율 버전으로 940908 공식 사례를 실행해 11,750,000원 재현.
- wheel 빌드 후 저장소 밖 임시 경로에 설치하여 규칙 JSON 패키징과 CLI 계산 확인.
- JSON·TOML 문법, 문서 내부 링크, Git 공백 검사 통과.
