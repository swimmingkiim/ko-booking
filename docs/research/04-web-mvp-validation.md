# 4단계: 로컬 웹앱 MVP

검증일: 2026-11-21. 완료 조건은 CSV 원본 보존, 거래 검토, 중복·환불 처리, 검토한 장부 내보내기와 기존 계산요소의 웹 사용이다.

## 실행·사용

README의 설치 후 `python -m ko_booking serve`로 실행하고 `http://127.0.0.1:8765`를 연다. 포트는 `--port`, 거래 DB는 `--ledger-db`로 지정한다. 공식 자료 카탈로그는 전역 옵션 `--db`로 지정한다. 종료는 Ctrl+C다.

1. 사업장 설정에서 연도별 과세유형을 확인한다. 유형은 자동 판정하지 않는다.
2. 자료 가져오기에서 CSV 열을 연결하고 미리보기 오류·중복을 확인한 뒤 저장한다. 예제 CSV는 합성 자료다.
3. 거래 검토에서 분류·분할·메모를 기록하고 환불과 중복 거래를 원거래에 연결한다.
4. 간편장부에서 증빙과 선택 연도 자료의 완전성을 확인한 뒤 장부 CSV를 내려받는다. 거래가 바뀌면 재확인한다. 미분류·제외 거래도 거래내역 CSV에는 남는다.
5. 세금·근거에서 2025년 계산요소를 수동 입력으로 확인한다. 경비율 계산에는 3단계에서 검증한 공식 원천 버전이 필요하다. 자료가 없으면 해당 계산을 비활성화한다.

CSV는 UTF-8 또는 CP949, 최대 2MiB·2,000행·50열이다. 날짜·거래처·입출금·금액을 필수로 연결하고 부가세·출처·거래번호는 선택한다. 금액은 원 단위 정수이며 환불은 원거래와 같은 입출금 방향의 음수로 기록한다. 부가세 빈칸은 미확인, 0은 확인한 0원이다. 동일 파일은 재등록하지 않으며 거래번호 없는 중복 후보는 사용자가 판단한다. 오류가 있으면 전체 가져오기를 차단한다.

## 장부 기준·지원 범위

대시보드는 부가세를 포함한 거래 총액을 표시한다. 개인거래·자금이동·중복은 집계에서 제외하고 자산취득·매각은 별도로 표시한다. 수입과 비용 차액은 과세소득이 아니다.

장부 수입은 일반과세자의 경우 확인한 부가세를 구분하고, 간이과세자·면세사업자는 총액으로 기록한다. 비용은 입력한 증빙의 부가세 구분을 따른다. 매입세액 공제 가능 여부는 판정하지 않는다. 과세유형 미확인, 필요한 부가세 미확인, 미분류·미연결 환불이 있으면 검토 완료 및 장부 내보내기를 막는다. 기준은 [국세청 간편장부 안내](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7670&mi=2231)의 작성요령을 참조했다.

단일 사업장·로컬 사용을 위한 검토용 정리표다. 간편장부 대상 자격, 연중 과세유형 변경·겸업, 감가상각·세무조정, 공제·가산세·기납부세액, 최종 납부세액과 홈택스 제출은 구현하지 않았다. 2026년 거래 정리는 가능하지만 계산 규칙은 2025년만 지원한다. 최신 세법 전체를 반영했다고 간주하지 않는다.

## 보관·구현

Python 표준 라이브러리 HTTP 서버와 SQLite, 빌드 없는 HTML/CSS/JavaScript를 사용한다. 루프백에만 바인딩하며 Host·Origin·요청 헤더를 검증한다. 외부 스크립트나 분석 도구를 호출하지 않는다. 인터넷 공개 운영을 위한 인증·권한·암호화·다중 사용자 기능은 없다.

원본 CSV 바이트와 가져오기 행은 보존하고 분류 변경은 수정 전후·리비전과 함께 기록한다. 새 개인자료 디렉터리와 DB는 각각 0700·0600 권한으로 생성한다. 기본 개인자료 경로는 Git 제외다. DB는 평문 로컬 파일이며 백업 시 개인자료로 관리해야 한다. CSV 내보내기는 텍스트의 수식 실행 문자를 처리한다.

## 검증 결과

- 전체 자동 테스트 55개 통과: 기존 수집·계산 33개와 가져오기·장부·HTTP 관련 22개. 원본 보존, 원자적 가져오기, 중복 충돌, 분할 합계, 동시 수정, 환불 금액·부가세 한도, 연도별 과세유형, 변경 후 재확인, CSV 및 요청 검증을 포함한다.
- `node --check ko_booking/static/app.js` 통과. wheel 빌드 및 정적 리소스 포함 확인.
- 실제 브라우저에서 합성 CSV 12건 가져오기, 분류·분할, 환불·중복 연결, 자료 확인 후 CSV 다운로드를 검증했다. 내보낸 11행을 재집계해 수입 10,450,000원·비용 1,551,000원·자산취득 1,650,000원과 대조했다.
- 면세사업자 수입 3,300,000원에서 일반과세자 장부 금액 3,000,000원·부가세 300,000원으로 설정 반영을 확인했다. 설정 변경 후 재확인과 내보내기 활성화를 확인했다.
- 계산 화면에서 과세표준 30,000,000원의 기본세율 계산요소 3,240,000원, 업종 940908 수입 45,000,000원의 소득금액 예제 11,750,000원을 확인했다. 2026년 계산 차단도 확인했다.
- 데스크톱 1440px 및 모바일 390px에서 대시보드·탐색·거래 편집을 확인했다. 최종 브라우저 경고·오류 로그는 없었다. 브라우저 검증은 일시적인 자동 승인 사용량 제한 후 재개해 완료했다.
