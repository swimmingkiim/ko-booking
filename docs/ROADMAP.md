# 단계별 진행 계획

## 진행 원칙

- 사용자의 요청: 순서대로 작업하고 단계마다 Git 커밋으로 기록한다.
- 단계가 끝나면 결과·검증·미확인 사항을 보고한다. 이번 작업에서는 1단계 보고에서 멈춘다.
- 공개 문서에서 확인한 사실, 제품 설계 제안, 실제 앱에서 확인하지 못한 사항을 구분한다.
- 개인 세무자료나 인증정보를 저장소에 넣지 않는다.

## 단계

| 단계 | 결과물 | 상태 |
| --- | --- | --- |
| 1. 머니핀·쌤157 분석 | 근거 목록, 기능 비교, 공통 시나리오, 초기 요구사항 | 공개 문서 조사 완료. 실제 계정 검증은 미수행 |
| 2. 공식 자료 수집기 | 법제처 API·국세청 경비율 XLSX 수집, 원문·메타데이터 보관, 변경 감지 | 대기 |
| 3. 계산 규칙 검증 | 국세청 예제의 입력·기대값, 규칙 버전·근거 연결 | 대기 |
| 4. 웹앱 MVP | 거래 파일 가져오기, 분류, 간편장부, 검증된 범위의 예상세액·근거, 내보내기 | 대기 |
| 5. 제출 지원 검토 | 홈택스 파일 명세 분석, 연동 어댑터, 제출·접수 상태 설계 | 대기 |

## 다음 단계 착수 시 확인

1. 법제처 API의 최신 명세와 인증값 제공 방법을 확인한다. 인증값은 환경변수로 받는다.
2. 경비율 자료의 귀속연도·첨부파일·원문 출처를 검증한다.
3. 시행일·귀속연도·수집일을 별도 필드로 보존한다.
4. 원문 데이터의 재배포 조건을 확인하고 코드 라이선스와 분리해 기록한다.
