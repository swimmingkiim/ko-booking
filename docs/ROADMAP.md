# 단계별 진행 계획

## 진행 원칙

- 사용자의 요청: 순서대로 작업하고 단계마다 Git 커밋으로 기록한다.
- 단계가 끝나면 결과·검증·미확인 사항을 보고하고 다음 단계 착수 전에 멈춘다.
- 공개 문서에서 확인한 사실, 제품 설계 제안, 실제 앱에서 확인하지 못한 사항을 구분한다.
- 개인 세무자료나 인증정보를 저장소에 넣지 않는다.

## 단계

| 단계 | 결과물 | 상태 |
| --- | --- | --- |
| 1. 머니핀·쌤157 분석 | 근거 목록, 기능 비교, 공통 시나리오, 초기 요구사항 | 공개 문서 조사 완료. 실제 계정 검증은 미수행 |
| 2. 공식 자료 수집기 | 법제처 API·국세청 경비율 XLSX 수집, 원문·메타데이터 보관, 변경 감지 | 구현·실자료 검증 완료. 운영 인증값·재배포 조건 미확인 |
| 3. 계산 규칙 검증 | 국세청 예제의 입력·기대값, 규칙 버전·근거 연결 | 대기 |
| 4. 웹앱 MVP | 거래 파일 가져오기, 분류, 간편장부, 검증된 범위의 예상세액·근거, 내보내기 | 대기 |
| 5. 제출 지원 검토 | 홈택스 파일 명세 분석, 연동 어댑터, 제출·접수 상태 설계 | 대기 |

## 2단계 착수 시 확인한 사항

1. 시행일 기준 API 명세 확인. 인증값은 환경변수 `LAW_OC`로 받는다.
2. 2025년 귀속 XLSX 1,542개 업종 실수집·파싱 검증.
3. 시행일·공포일·귀속연도·수집시각을 구분해 보존.
4. 국세청 자료 재배포 조건 미확인을 기록하고 원문·정형 자료는 Git에서 제외.

[2단계 검증 기록](research/02-collection-validation.md)과 [사용법](collectors.md)을 참조한다.
