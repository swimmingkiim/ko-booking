# ko-booking

한국 개인사업자의 거래 정리, 장부 작성, 세금 계산 근거 확인을 돕는 오픈소스 웹앱 프로젝트입니다.

현재는 공식 자료 수집기와 2025년 귀속의 일부 계산요소를 구현한 단계입니다. 웹앱과 최종 납부세액 계산 기능은 아직 없습니다. 코드 배포 라이선스는 아직 결정하지 않았으며 원천 자료의 이용조건과 별도로 관리합니다.
