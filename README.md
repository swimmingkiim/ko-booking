# ko-booking

한국 개인사업자의 거래 정리, 장부 작성, 세금 계산 근거 확인을 돕는 오픈소스 웹앱 프로젝트입니다.

현재는 조사·요구사항 정의 단계입니다. 실행 가능한 앱과 검증된 세액 계산 기능은 아직 없습니다. 오픈소스 배포 라이선스는 구현 코드 도입 전에 결정합니다.
